# Сторонние компоненты и ассеты

Проект распространяется по лицензии **PolyForm Noncommercial 1.0.0** (см.
`LICENSE`). Ниже — что внутри использует чужие материалы и на каких условиях.
Лицензия проекта не отменяет их условий: атрибуцию нужно сохранять.

## Шрифты

| Файл | Что это | Лицензия |
|---|---|---|
| `fonts/noto_sans.ttf` | Noto Sans, шрифт интерфейса по умолчанию | SIL Open Font License 1.1, текст — `fonts/LICENSE-Noto.txt` |

Пользовательские шрифты из папки `fonts` рядом с программой не входят в
поставку: их добавляет сам пользователь, и на них распространяются условия их
авторов.

## Звуки и музыка

| Файл | Что это | Лицензия |
|---|---|---|
| `sounds/` (move, capture, twilight) | синтезируются кодом при первом запуске (`src/sound.rs`), не являются чужими файлами | лицензия проекта |
| `music/theme.wav` | фоновая музыка | см. примечание ниже |

**Примечание по `music/theme.wav`:** в прототипе лежит файл, происхождение
которого не установлено (взят из открытого канала, автор и лицензия
неизвестны). Для прототипа это терпимо, но в публичный релиз его нельзя
включать как часть проекта. Варианты на замену: сгенерировать тему скриптом
`tools/gen_theme.py` (у неё нет чужих прав) или взять трек с лицензией
CC0. После замены эта строка обновится.

## Графика

- `assets/icon-256.png`, `assets/icon.ico` — иконка проекта, нарисована для него.
- `pieces/*.svg`, `packs/frog/pieces/*.png` — фигуры проекта, нарисованы для него.
- Стилизованные шахматные иконки на шашках рисуются кодом (`src/art.rs`).

## Программные библиотеки

Игра собрана на Rust и использует открытые крейты (eframe/egui, image, resvg,
puremp3, snow, socket2 и их зависимости). Все они распространяются по
permissive-лицензиям (MIT, Apache-2.0, BSD, Zlib, OFL для шрифтов) — их
условия разрешают включать код в бинарник при сохранении уведомлений об
авторских правах.

Полный список версий — в `Cargo.lock`. Тексты лицензий каждого крейта лежат в
его исходниках на crates.io; при необходимости их можно собрать автоматически
(`cargo about`, `cargo-license`).

## Что делать при добавлении нового ассета

1. Проверить лицензию: разрешает ли она использование и распространение в
   некоммерческом проекте.
2. Добавить строку в таблицу выше: файл, что это, лицензия, ссылка на источник.
3. Положить текст лицензии рядом с ассетом (например,
   `fonts/LICENSE-Noto.txt`) или в `licenses/`.
4. Если лицензия требует указания автора — указать его в этой таблице.
