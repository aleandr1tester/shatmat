# Сумерки — гибрид шахмат и шашек

Прототип настольной игры: одна доска, две игры. Фигуры «дышат» и раз в
несколько секунд переживают сумеречный переход — волна из центра доски
превращает шахматные фигуры в шашки (и обратно), и правила меняются вместе
с ними.

## Как играть

- Клик по фигуре — выбрать, клик по подсвеченной клетке — сделать ход.
- `Space` — пауза, `R` — новая партия, `H` — правила, `Esc` — снять выбор.
- Ход и взятие сопровождаются короткими звуками.
- В панели справа: текущая фаза, обратный отсчёт, чей ход, журнал ходов,
  темп превращений (15, 25 или 40 секунд) и соперник.

## Режимы

- **Вдвоём** — два игрока за одной доской, ходы по очереди.
- **С компьютером** — вы играете белыми, компьютер отвечает чёрными.
  Сложность выбирается тут же: «легко» (ходит почти случайно), «средне»
  (считает на два полухода) и «сложно» (на три, с отсечением вариантов).
  Компьютер думает полсекунды и уважает все правила фазы, включая
  обязательные взятия и серии прыжков.

## Стартовая позиция

Партия начинается с классической расстановки: по 16 фигур у каждого —
8 пешек и 8 фигур (ладьи, кони, слоны, ферзь и король).

## Правила

### Когда фигуры — шахматы

- Ходы классические: пешка, конь, слон, ладья, ферзь, король.
- Без рокировки и взятия на проходе.
- Пешка на последнем ряду превращается в любую выбранную фигуру: ферзя,
  ладью, слона или коня.
- Шах и мат работают: короля нельзя оставить под боем.
- Пат — ничья.

### Когда фигуры — шашки

- Простые шашки (пешки и кони) ходят по диагонали вперёд и назад, а бьют в
  любую сторону.
- Шашка остаётся на клетках своего цвета: ход по диагонали всегда сохраняет
  цвет поля.
- Можно подставляться под удар, если обязательного взятия нет.
- Дамки (слоны, ладьи, ферзь, король) летят по диагонали на любое расстояние.
- Король в шашечной фазе помечен маленькой точкой над короной — его видно
  среди других дамок.
- Бить обязательно; серия взятий продолжается, пока есть цель.
- Простая шашка, дошедшая до последнего ряда, становится дамкой.
- Фигура-король в шашечной фазе — тоже дамка: её можно съесть и победить.
- Если ходить нечем — ход переходит сопернику. Если застряли оба, сумерки
  запускаются сразу и временно выводят в шахматы, чтобы выйти из тупика.

### Сумерки

- Переход длится 1,7 секунды: ходы замирают, волна света идёт от центра к
  краям, фигуры перетекают друг в друга.
- Переход ждёт, пока игрок завершит серию взятий.
- Если в шашечной фазе застряли оба, переход запускается сразу — это временный
  выход в шахматы; после него обычный цикл продолжается.
- Победа: мат, съеденный король или у соперника не осталось фигур.

## Сборка и запуск

Проект лежит в рабочей папке DSH:
`<домашняя папка>\Documents\deepseek-harness\default-workspace\shatmat`.
Windows не даёт компилятору писать в `Documents`, поэтому локальный
`.cargo/config.toml` (не в git) направляет сборку в `AppData\Local`.

```sh
cargo run --release
```

Снимок окна для проверки (путь лучше указывать вне Documents):

```sh
cargo run --release -- --screenshot "$env:TEMP/now.png"
```

В режиме снимка окно открывается без фокуса и за другими окнами, рисует около
120 кадров, сохраняет PNG и закрывается.

Проверка правил:

```sh
cargo test
```

## Устройство

- `src/game.rs` — правила: ходы, взятия, превращения, статусы партии.
- `src/art.rs` — палитры фаз, векторные фигуры и шашки, эффекты.
- `src/sound.rs` — короткие звуки хода и взятия (WAV из памяти через winmm).
- `src/main.rs` — окно, раскладка, панель, правила, режим снимка.
