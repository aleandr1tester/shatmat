Custom interface fonts
======================

The default font is Noto Sans (built in). It covers Cyrillic and Latin,
including Turkish letters (ğ, ş, ı, İ), so it fits every game language and
reads better at small sizes. Prosto sits next to it and can be picked in the
settings as an alternative.

Put .ttf or .otf files in this folder and restart the game.
In the settings press the "Font: …" button to choose the next font
from the list.

The files noto_sans.ttf and prosto.ttf are here for reference and are not
duplicated when choosing. The Noto Sans licence is in LICENSE-Noto.txt
(SIL Open Font License 1.1).

The folder is next to shatmat.exe.
