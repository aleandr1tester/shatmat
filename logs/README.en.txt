Game logs for ModeShift: Bipolar.

The game creates one text file per game in this folder:
  game-YYYY-MM-DD-HH-MM-SS.txt

What is recorded:
  - start and end time;
  - game mode (two players / vs computer and difficulty);
  - phase times: chess and checkers separately;
  - the result of the game;
  - every move: number, side, piece, coordinates (for example, e2-e4),
    capture and phase (chess / checkers);
  - total moves, separately for White and Black, full moves.

An interrupted game is also saved with a note.

You can enable or disable recording in "Settings" → "Game logs".
After a game, the move journal can be opened with the "Journal" button on
the result card.
