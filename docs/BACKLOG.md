# Бэклог ShatMat

Идеи и задачи, которые не вошли в текущую сборку. Файл живёт в репозитории,
чтобы не терять мысли: периодически выхватываем отсюда одну-две штуки и
делаем. Статусы: `идея` — не начато, `в работе` — делается сейчас,
`готово` — сделано (строку можно удалить при следующей уборке).

Приоритет: `A` — заметно влияет на игру или на вход новичка, `B` — приятно и
полезно, `C` — когда-нибудь.

### Как пользоваться

1. Открыть файл, выбрать 1–2 пункта с приоритетом `A`.
2. Поставить `в работе`, сделать, отметку `готово` (или удалить строку).
3. Новые мысли дописывать сюда же, не теряя старые.
