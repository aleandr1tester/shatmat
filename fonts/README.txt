Свои шрифты интерфейса
======================

Шрифт по умолчанию — Noto Sans (встроен). Он поддерживает кириллицу и
латиницу, включая турецкие буквы (ğ, ş, ı, İ), поэтому подходит для всех
языков игры и хорошо читается мелким кеглем.

Положите в эту папку файлы .ttf или .otf и перезапустите игру.
В настройках нажмите кнопку «Шрифт: …», чтобы выбрать следующий шрифт
из списка.

Файл noto_sans.ttf лежит здесь для наглядности и не дублируется при выборе. Лицензия Noto Sans — в LICENSE-Noto.txt
(SIL Open Font License 1.1).

Папка находится рядом с shatmat.exe.
